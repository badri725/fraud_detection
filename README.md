# Fraud Detection

## Project Overview
This project explores fraud detection using transaction data (`pay1.csv`) and a Jupyter notebook (`fraud_detection.ipynb`) for analysis and modeling.

## Files
- `fraud_detection.ipynb` — main analysis/model notebook
- `pay1.csv` — transaction dataset

## How to Run
1. Clone this repository
2. Open `fraud_detection.ipynb` in Jupyter
3. Ensure `pay1.csv` is in the same directory
